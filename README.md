# 电柜快画（DKK）

> 面向非标电柜/电气设计的小工具：输入柜体尺寸、门板开孔和内部器件，自动生成可用于机械加工的**柜体接口图**，输出黑白 CAD 风格的 PDF / SVG / PNG。

当前版本：**v0.5.1**（修复导轨新建/拖动交互：新建导轨自动适配安装板、器件不再默认新建导轨、点器件也能整体拖动导轨；保留琴式操作台、快速放器件目录、撤销/重做、DXF/CSV 导出等能力）。支持五个面开孔/腰型孔，安装板内拖动、方向键微调与复制粘贴导轨/线槽。Python + matplotlib + Tkinter，单文件 EXE 打包脚本见 `build_exe.bat`。

---

## 1. 解决什么问题

非标电柜设计中最耗时、最容易返工的环节之一，是电气设计把「门板上开哪些孔、孔在哪、柜内装什么、安装板多大」准确交给机械/钣金。口头描述容易错，画完整 CAD 又太重。

电柜快画把这件事变成参数化模板：

1. 选柜型，填外形尺寸；
2. 从元件库选按钮、指示灯、触摸屏、仪表等，按坐标摆放，支持等间距阵列；
3. 布置导轨、断路器、端子、线槽；
4. 选技术要求模板，填写图框信息；
5. 一键输出 A3/A2/A1 图纸（PDF 矢量，可直接发机械厂）。

工具只做「壳体接口确认图」，不做电气原理图、接线图和钣金展开图，边界清晰。

## 3. 快速开始

### 3.1 运行环境

- Windows 10/11（开发验证环境：Windows 11 + Python 3.12）
- Python 3.10+
- 依赖：`matplotlib`（Tkinter 随 Python 安装）

```bat
py -m pip install -r requirements.txt
py main.py
```

也可以直接双击 `main.py`，或运行 `py -m dkk`。无需安装数据库、浏览器或其他运行时。

首次启动会载入内置示例 `data/examples/demo_1700x1900x460.json`。琴式操作台示例见 `data/examples/demo_console_1200x1100x750.json`（A2/1:15，17 个开孔、2 根导轨）。

### 3.2 命令行批处理

```bat
py main.py --cli --png -o output\我的图纸.pdf
py main.py --cli data\examples\demo_1700x1900x460.json -o output\demo.pdf
py main.py --cli -o output\demo.dxf        # DXF（R12，单位 mm）
py main.py --cli -o output\demo.csv        # 开孔表 + 材料表 + 导轨表
py main.py --cli --csv -o output\demo.pdf  # 出 PDF 同时附带同名 CSV
py main.py --cli --no-sizes -o output\demo.pdf  # 不标注开孔尺寸
```

也可以直接：

```bat
py -m dkk.cli data\examples\demo_1700x1900x460.json -o output\demo.svg
```

命令行会打印校验问题、图幅和比例。

### 3.3 打包 EXE

```bat
build_exe.bat
```

产物：`dist\电柜快画.exe`（v0.5.1 本机实测约 43 MB）。首次启动需要解压，通常等待 2–10 秒；单文件包含 matplotlib，体积随环境不同，约 40–120 MB。体积主要来自 numpy/matplotlib/Tk，已排除未使用的 Qt、WebAgg、GTK、WX 等后端；若追求压缩率可自行安装 UPX 后重新打包。杀毒软件可能对 PyInstaller 单文件误报，可改用文件夹版或将 `dist` 加入白名单。

已在本机验证：打包后的 EXE 可正常启动 GUI 并显示示例预览；`--cli` 导出 PDF/SVG/PNG/DXF/CSV 均成功。尚未在未安装 Python 的干净机器上验证，交付前建议复制到目标电脑实测一次。

### 3.4 文件夹版（闪退/受限电脑排查）

如果双击单文件 EXE 后窗口一闪就消失，通常是单文件运行时解压到临时目录被安全软件拦截，或 `%TEMP%` 权限受限。可改用文件夹版：

```bat
build_folder.bat
```

产物为 `dist\电柜快画_文件夹版\`，双击其中的 `电柜快画_文件夹版.exe`。它不需要解压，启动更快，也更容易加入杀毒软件白名单；整个文件夹需一起复制，不能只拷 exe。

程序会把启动和异常信息写入：

```
%LOCALAPPDATA%\电柜快画\app.log
```

界面右下角的「日志」按钮可直接打开该目录。若仍然闪退，请把 `app.log` 发给开发者；若日志文件根本没有生成，说明 EXE 在启动前就被系统/安全软件拦截，优先尝试文件夹版并加入白名单。

## 4. 界面使用

### 4.1 柜体 / 图框

- **柜型模板**：切换后自动载入该柜型的推荐尺寸，也可随时点「载入推荐尺寸」恢复。切到琴式操作台时，如果已有开孔/导轨，会提示是否清空后按琴柜重新布置。
- **琴式操作台**：除 W/H/D 外，还需填「前沿高（琴柜）」和「后平顶深（琴柜）」。斜面展开长度由 `√((D-后平顶深)² + (H-前沿高)²)` 自动计算，正视图按「门板 + 斜面展开」绘制，斜面开孔填沿斜面量取的真实尺寸。
- **开孔坐标基准**：正面以柜体正面左下角、侧面以侧板前下角、顶底板以该板左前角为原点，单位 mm，详见第 5 节。
- **图幅/比例**：默认「自动」。自动模式会从 A3→A2→A1 依次尝试，并选择不超过 1:20 的合适比例；也可以强制指定，校验面板会提示是否放不下。
- **输出视图**：可只输出正视图，或关闭安装板图等。

### 4.2 开孔（五个面）

- **所在面**：对话框第一行选择「正面（门板）/ 左侧板 / 右侧板 / 顶板 / 底板」。默认新增时按当前视图带入：正视图→正面，侧视图→左侧，俯视图→顶板。
- 「添加 / 阵列」：选元件和所在面，填 X/Y、数量、水平/垂直间距、代号前缀。元件较多时可在对话框右上角「搜索」框输入关键字（如 `触摸屏`、`22`、`急停`）快速过滤。
  - 数量 > 1 时自动生成阵列；前缀末位是数字会递增，例如 `HL1` × 6 → `HL1…HL6`，`SB10` × 3 → `SB10…SB12`。
  - 代号前缀不含数字时，自动补 1、2、3…；数量为 1 时代号原样使用。
  - 自定义方孔/圆孔/腰型孔需填「开孔宽/高」或「开孔直径」；腰型孔 W×H 为两端圆弧的外形尺寸。
  - 对话框内带**所在面示意图**：可直接点击或拖动定位，实时显示孔心距该面四边的距离。
- 双击一行编辑；支持多选删除。**孔位编号统一按录入顺序**，图纸引出编号、孔位表行号、界面表格行号和校验提示里的 `#编号` 完全一致。
- **预览内直接定位**：正视图、侧视图、俯视图里的开孔都可以直接拖动；双击孔打开编辑，双击空白处在当前位置添加（侧视图默认左侧板，俯视图默认顶板）；右键孔可编辑/复制/删除。安装板布置图里的导轨/线槽同样可直接拖动，详见 4.3。
- **键盘微调**：在预览中单击选中开孔、导轨或线槽后，方向键每次移动 1mm，Shift+方向键每次 10mm。
- **复制粘贴**：Ctrl+C / Ctrl+V 复制粘贴选中的开孔、导轨或线槽；多选时整组复制。粘贴的开孔会清空代号，避免出现重复代号。
- **位置微调**：选中开孔后，用 X/Y 滑杆左右/上下移动，右侧数值框可输入精确值；多选时一起移动，标尺和限位会按每个孔所在面自动切换（正面 X 距左/Y 距下，侧面 X 距前/Y 距下，顶底面 X 距左/Y 距前）。
- **视图放大**：预览右上角选择「正视图 / 侧视图 / 俯视图」，会自动放大并滚动到对应视图，拖动更精确；中键拖动可平移画布，Shift+滚轮横向滚动。

### 4.3 内部布置

- **导轨**：Y 为导轨中心距安装板下沿；X 和长度留空表示自动。新建导轨默认取一段合适长度（最长 600mm，并留出左右拖动余量），不再默认铺满整板；右击空白处新建时以点击点为中心、自动平移或缩短，保证不越界。双击导轨可改长度/起点。
- **快速放器件**：点「快速放器件」打开常用器件目录，可按分类/名称/品牌/型号搜索；选中后自动带出品牌、规格和宽度/高度，可直接修改后「添加」或「添加并继续」。**已有导轨时默认追加到最后一根，不会自动新建导轨**；只有明确选择「新建导轨」才会创建新导轨。这是“够用”的折中库，不追求覆盖所有品牌型号。
- **器件表达式**：`2P×6, 3P×4`、`2P*6;3P*4` 均可，支持中文逗号/分号。
- 器件会按表达式顺序从左到右排布，并按型号前缀自动编号（QF、KM、KA、G、X…）。
- **线槽**：垂直槽从 (X,Y) 向上延伸，水平槽向右延伸；坐标基准是安装板左下角。
- **预览内直接调整**：在「安装板布置图」中单击导轨或线槽即可选中并拖动；**点导轨上的器件本体也能整体拖动导轨**。拖动时实时显示 X/Y、距安装板右边/上边的距离，松手后表格坐标同步更新。
  - 导轨是器件安装基准，拖动导轨会带着上面的器件一起移动；到左/右边界时状态栏会提示，双击导轨缩短长度后可继续移动。
  - 双击导轨/线槽打开编辑对话框；双击空白处在该位置添加线槽。
  - 右键导轨/线槽可编辑或删除；右键空白处可「在此添加线槽/导轨」。
  - 也可以先在表格里选中被挡住的线槽，再在预览中拖动，避免重叠时选不中。
  - 在预览中单击选中后，可直接按**方向键**微调 1mm；**Shift+方向键** 每次 10mm。
  - **Ctrl+C / Ctrl+V** 复制粘贴选中的导轨或线槽（可先在表格里多选）。粘贴自动错开 40～45mm，避免完全重叠。
  - 校验会自动提示导轨与线槽、导轨之间、线槽之间的重叠。
- **视图放大**：预览右上角选择「安装板图」可放大到安装板区域再拖动。

### 4.4 技术要求

- 选择模板（通用控制柜 / 壁挂箱 / 琴式操作台 / 精简版），模板条目中的变量会自动替换。
- 下方文本框可追加条目，每行一条，排在模板条目之后。
- 支持的变量：`{W} {H} {D} {t} {material} {color} {ip} {base} {plate_w} {plate_h} {door_type} {cabinet_type} {hinge}`。

### 4.5 预览与导出

- 工具栏「琴柜示例」可一键载入 `data/examples/demo_console_1200x1100x750.json`，查看斜面展开、侧视轮廓和后部平顶开孔的完整画法。
- `F5` 或「刷新预览」重新出图；预览右上角可切换「适合窗口 / 正视图 / 侧视图 / 俯视图 / 安装板图 / 50% / 75% / 100% / 150%」，放大后可用滚轮/滚动条/中键拖动查看细节。
- 预览刷新复用同一个画布，只重绘图形内容，不会销毁/重建控件，因此放置线槽或控件时不再闪屏。
- 柜体尺寸、图幅比例、图框文字改动后会自动刷新（约 0.7 秒防抖）；输入暂时不完整时不会弹错，补全后自动出图。
- 生成失败时保留上一张成功图纸并在状态栏提示，不会出现空白画布。
- 「柜体 / 图框」页的「标注开孔尺寸」可随时关闭/打开尺寸标注，导出同步生效。
- 「导出 PDF / SVG / PNG / DXF」会先重新生成，保证与当前参数一致；「导出表格 CSV」输出开孔表、材料表、导轨元件表。
- 支持撤销/重做，覆盖开孔、导轨、线槽、柜体参数和图框信息。
- 「保存项目」保存为 JSON；「打开项目」可继续编辑。项目文件建议放在 `data/examples/` 或自己的工程目录。

快捷键：`F5` 刷新，`Ctrl+S` 保存项目，`Ctrl+O` 打开项目，`Ctrl+E` 导出 PDF，`Ctrl+Z` 撤销，`Ctrl+Y`（或 `Ctrl+Shift+Z`）重做。预览选中对象后：方向键微调 1mm，`Shift+方向键` 10mm，`Ctrl+C/Ctrl+V` 复制粘贴。

## 5. 坐标与比例约定

| 对象 | 原点 | 方向 | 说明 |
|---|---|---|---|
| 正面开孔 | 门板左下角（柜体正面） | X 向右，Y 向上 | X 指距柜体左边，Y 指距底面 |
| 琴柜正面开孔 | 正面左下角（展开图） | X 向右，Y 向上 | Y ≤ 前沿高为门板；Y > 前沿高为斜面展开区，Y 为沿斜面量取的真实长度；折弯线附近不可跨孔 |
| 左/右侧板开孔 | 侧板前下角 | X 由前向后，Y 向上 | X 距前，Y 距下；左孔在侧视图实线，右孔虚线；琴柜侧板孔须落在实际轮廓内 |
| 顶/底板开孔 | 该板左前角 | X 向右，Y 由前向后 | X 距左，Y 距前；顶孔在俯视图实线，底孔虚线；琴柜顶面只有后部平顶可开孔 |
| 导轨/线槽 | 安装板左下角 | X 向右，Y 向上 | 导轨 Y 为中心线 |
| 柜体尺寸 | — | — | W 宽、H 高、D 深；底座单独计高 |
| 琴柜尺寸 | — | — | 前沿高 `console_desk_h`；后平顶深 `console_top_depth`；斜面水平投影 = D − 后平顶深；斜面升高 = H − 前沿高；斜面展开长 = √(投影² + 升高²) |
| 安装板 | — | — | `plate_w = W - 2×plate_margin`；`plate_h = H - base_height - plate_bottom_gap - plate_margin`；琴柜为 `plate_h = console_desk_h - base_height - plate_bottom_gap - plate_margin` |

图纸坐标统一为 mm，按所选比例缩放到 A3/A2/A1 图纸；PDF/SVG 为矢量，文字以 TrueType 子集嵌入（SVG 转路径），不依赖目标机器字体。

```json
    {"y": 220, "x": 100, "length": 1440,
     "devices": [{"model": "2P", "qty": 6},
                 {"model": "3P", "qty": 4}]}
  ],
  "ducts": [
    {"x": 30, "y": 80, "length": 1560, "width": 60, "orient": "v"}
  ],
  "sheet": {
    "size": "auto", "scale": "auto",
    "project": "1700×1900×460 非标控制柜壳体接口图",
    "drawing_no": "DG-2026-001", "version": "A",
    "designer": "电气设计", "checker": "机械确认",
    "date": "", "company": "XX电气自动化有限公司", "remark": ""
  },
  "req_set": "standard",
  "custom_requirements": [],
  "views": ["front", "side", "plan", "internal"]
}
```

字段说明：

- `component`：`data/components.json` 的键，如 `pushbutton_22`、`hmi_10`、`custom_rect`、`custom_slot`。
- `face`：`front` 正面（默认）、`left` 左侧板、`right` 右侧板、`top` 顶板、`bottom` 底板。
- `w/h/d`：任务级尺寸覆写，0 表示用元件库值；圆孔用 `d`，方孔和腰型孔用 `w/h`。
- `orient`：`v` 垂直槽，`h` 水平槽。
- `size`：`auto` / `A3` / `A2` / `A1`；`scale`：`auto` / `1:5` … `1:50`。
- `views`：`front` 正视图、`side` 侧视图、`plan` 俯视图、`internal` 安装板图。
- `req_set`：`data/requirements.json` 的键。
- 日期留空时自动使用当天日期。
- 琴柜项目 `cabinet.template` 填 `console`，并增加 `console_desk_h`（前沿高）和 `console_top_depth`（后部平顶深）；旧项目缺少这两个字段时按默认值 720/250 处理。
- 器件组可覆写品牌/名称/型号/宽高：`{"model":"2P","qty":6,"brand":"正泰","name":"微型断路器","spec":"NXB-63 2P","width":36}`；覆写值优先于 `devices.json`。

## 7. 扩展元件库 / 器件库

所有库都是普通 JSON，改完重启程序即可生效。打包后的 EXE 会优先读取 **EXE 同目录下的 `data/`**（其次读取打包内置库），因此把 `data` 文件夹复制到 EXE 旁边即可自定义元件库、器件库和模板，无需重新打包。也可以用环境变量 `DKK_DATA_DIR` 指定其他数据目录。

### 7.1 `data/components.json`

```json
"my_hmi": {
  "name": "触摸屏 15寸",
  "category": "HMI",
  "cutout": {"type": "rect", "w": 380, "h": 240, "r": 3},
  "outline": {"type": "rect", "w": 395, "h": 255, "r": 4}
}
```

- `cutout`：实际开孔（实线）；
- `outline`：元件外形/安装法兰（虚线），用于干涉校验和美观；
- 圆孔用 `{"type":"circle","d":22.5}`；
- 腰型孔用 `{"type":"slot","w":120,"h":30}`，W/H 为两端圆弧的外形尺寸，绘图时自动生成两端半圆；
- `custom: true` 的条目允许在任务里覆写尺寸。

### 7.2 `data/devices.json`

```json
"contactor_18": {
  "name": "交流接触器 18A",
  "category": "接触器",
  "brand": "正泰",
  "width": 54, "height": 85,
  "prefix": "KM", "spec": "CJX2-1810"
}
```

- `width`：35mm 导轨上的占用宽度（微断常用 极数×18mm）；
- `height`：器件在安装板上的高度；
- `prefix`：自动编号前缀；
- `brand`：快速放器件目录显示的默认品牌；
- `category`：快速放器件目录的分类；
- `spec`：材料表「规格/型号」列显示的文本，可改成实际品牌型号。

快速放器件只是常用型号的“折中目录”：选中后品牌、规格、宽度、高度都能在对话框里改写，不需要为每个品牌单独建库。项目 JSON 中的 `DeviceItem` 会保存 `brand/name/spec/width/height/prefix` 覆写值，重新打开仍保留。

### 7.3 `data/templates.json`

柜型模板及推荐尺寸。`enabled: false` 的条目不会出现在界面。琴式操作台的 `defaults` 除 W/H/D 外还包含 `console_desk_h`（前沿高）和 `console_top_depth`（后部平顶深）。

### 7.4 `data/requirements.json`

技术要求模板。条目中可使用变量；`items` 为字符串数组。新增模板后会自动出现在界面下拉框中。

## 8. 图纸内容与校验

### 8.1 一张图包含

1. 图框、标题栏（单位/项目/图号/比例/版本/日期/设计/审核/张数）；
2. 正视图：柜体外形、门板、铰链/把手示意、开孔、外形尺寸链；琴柜为「门板 + 斜面操作面板展开图」，并标出折弯线、斜面展开长和前沿高；
3. 侧视图、俯视图：深度方向接口，左侧板/顶板开孔实线，右侧板/底板开孔虚线，并带引出编号；琴柜侧视图为真实斜面轮廓，俯视图区分斜面投影和后部平顶；
4. 安装板布置图：安装板尺寸、导轨、器件、线槽、导轨编号；
5. 开孔表：编号、所在面、元件、开孔尺寸、X/Y、代号/备注；
6. 柜内元件材料表：名称、规格/型号、数量；
7. 导轨元件表：每根导轨的器件分组与自动编号范围；
8. 技术要求：模板 + 自定义条目，自动分栏、自动缩小字号以适应图幅。

开孔编号规则：与界面表格一致，统一按**录入顺序**编号；引出线采用行分组布局，避免长距离交叉。

### 8.2 校验规则

| 级别 | 规则 |
|---|---|
| 错误 | 开孔超出所在面范围（正面门板 / 左/右侧板 / 顶/底板） |
| 错误 | 双开门正面开孔跨越中缝 |
| 错误 | 同一面孔间外形干涉（含 3mm 间隙），不同面互不干涉 |
| 错误 | 导轨 Y 超出安装板或 X/长度超宽 |
| 错误 | 导轨上器件总宽超过导轨长度 |
| 错误 | 器件超出导轨末端 |
| 错误 | 导轨与线槽重叠 |
| 错误 | 导轨之间重叠 |
| 提示 | 线槽之间平行重叠、几乎完全重合或十字交叉（转角/T 形搭接不提示） |
| 错误 | 琴柜前沿高/后平顶深/斜面水平投影/升高不合理 |
| 错误 | 琴柜正面开孔跨越折弯线，或斜面展开区开孔超出展开高度 |
| 错误 | 琴柜顶面开孔落在斜面投影区（只有后部平顶可开孔） |
| 错误 | 琴柜侧面开孔超出实际斜面/平顶轮廓 |
| 错误 | 柜体尺寸/底座/门板净高/安装板尺寸不合理 |
| 提示 | 开孔距所在面边缘 < 15mm |
| 提示 | 线槽超出安装板 |
| 提示 | 没有开孔 / 没有导轨 |
| 提示 | 指定图幅或比例放不下、比例过小 |
| 提示 | 材料表/导轨表空间不足 |

校验不替代人工复核；图纸输出前请重点检查开孔基准、双开门中缝、器件实际尺寸和安装板厚度。

### 9.1 分层约定（二次开发请遵守）

| 层 | 模块 | 职责 | 不应做的事 |
|---|---|---|---|
| 数据层 | `model.py` | 数据类、JSON 序列化、表达式解析 | 不导入 Tkinter / matplotlib |
| 资源层 | `library.py` | 读取并解析 `data/*.json` | 不画图、不弹窗 |
| 几何层 | `views.py` | 纯几何：门板、五金、导轨、线槽、安装板布置 | 不读写文件、不依赖 GUI |
| 校验层 | `validate.py` | 基于 `Job` 输出 `Issue` 列表 | 不直接弹窗；由 GUI/CLI 决定如何展示 |
| 出图层 | `sheet.py` / `fonts.py` / `dxf.py` | Figure 绘制、图幅比例、表格、DXF 转换 | 不修改业务数据 |
| 导出层 | `export.py` | PDF/SVG/PNG/DXF/CSV 落盘 | 不包含界面逻辑 |
| 表现层 | `gui.py` / `cli.py` / `main.py` | 参数收集、预览、交互、命令解析 | 不复制几何/校验算法，统一调用上面各层 |

新增功能时建议顺序：先改数据模型 → 在 `views.py` 增加纯函数（配套单元测试）→ 在 `validate.py` 加规则 → 最后接 GUI/CLI。这样打包、CLI 批处理和界面共用同一套几何，不会出现“预览对、导出错”。

## 10. 已知限制与二期规划

**当前限制**

- 只支持单页图纸；超大柜体在 A1 上仍可能拥挤。
- 顶板/底板/侧板按平板表达，不表达折边、加强筋、吊环和并柜接口；现场进线腰型孔可按实际位置添加。
- 门板五金（铰链、把手、锁）为示意画法，不表达真实型号与安装孔位。
- 器件编号按前缀全局递增，暂不支持手动指定编号或跨页编号。
- 已支持 DXF（R12，mm），但尚未输出 DWG；需要 DWG 时可在 CAD 中另存。DXF 以 GBK（ANSI_936）写入中文，适配中文版 AutoCAD/浩辰/中望。
- 没有电气逻辑校验（电压、电流、回路），不替代电气设计。
- 琴柜正视图是“门板 + 斜面展开”的展开图，不是三维/钣金展开图；斜面折弯半径、回弹和焊接坡口需机械厂按工艺处理。顶面仅后部平顶可开孔，斜面本身不按顶面开孔处理。
- 快速放器件是常用型号的折中目录，不是完整品牌数据库；实际品牌/型号/宽度请在对话框中改写，并以厂家样本为准。
- 琴柜侧板开孔必须落在实际斜面/平顶轮廓内，不能按矩形侧板随意放。
- 技术要求/材料表在极端条目数量下会自动压缩，建议控制在合理范围。
- 撤销栈最多 100 步，仅供当前会话使用，保存/打开项目不会写入撤销历史。

**二期候选**

- 更完整的品牌型号库与器件图标预览；
- 门板开孔自动排版（避让中缝/铰链/把手）；
- 多页图纸、柜体分区、并柜接口；
- 图框/技术要求模板可视化编辑器；
- 项目文件版本兼容与迁移。

## 11. 常见问题

**Q：PDF 里中文变成方框/缺字？**
A：程序会自动查找 SimHei、Microsoft YaHei、Noto Sans CJK 等字体；如果系统都没有，请安装中文字体，或把 `.ttf/.ttc` 放到 `data/fonts/` 后重启。PDF 使用 TrueType 子集嵌入，跨机器打开一般不需要字体。

**Q：自动图幅总是偏大/偏小？**
A：可在「图框信息」里强制指定 A3/A2/A1 和 1:10/1:15 等比例；校验面板会提示是否放得下。柜体越大，建议 1:20～1:30 并选 A1。

**Q：开孔/导轨位置为什么和预期相反？**
A：正面开孔原点在柜体正面左下角，侧面开孔在侧板前下角（X 距前），顶底板开孔在该板左前角（Y 距前）；导轨/线槽原点在安装板左下角。双开门正面还要避开中缝。

**Q：命令行中文输出乱码？**
A：这是 Windows 控制台代码页问题，不影响 PDF/SVG/JSON 内容。可在 PowerShell 中执行 `chcp 65001` 或使用 Windows Terminal。

**Q：EXE 启动很慢 / 被杀毒拦截？**
A：PyInstaller 单文件需要解压到临时目录；可将 `--onefile` 改为 `--onedir`，或使用代码签名/白名单。打包体积主要来自 matplotlib。

- 开孔尺寸就地标注：触摸屏、仪表、按钮/指示灯等开孔旁直接标注尺寸；规格相同的小孔按行合并（如 `Φ22.5×6`），大孔单独标注；放不下的尺寸汇总到视图标题下方（`开孔尺寸：…`）。
- 线槽填充加深为灰色 `#c6c6c6` 并加中粗轮廓，在安装板图中与 35mm 导轨明显区分。
- 开孔对话框的所在面示意图按实际尺寸绘制当前元件并显示规格，摆放时即可判断大小。
- 新增回归测试：图幅复用、尺寸标注、线槽填充。
